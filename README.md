# ☕ Сайт ЗЕРНО

Современный адаптивный сайт для кофейни с уютным визуальным стилем и акцентом на атмосферу заведения.

## ✨ Основные возможности

* ☕ Меню напитков и десертов
* 📖 Информация о кофейне
* 🖼️ Галерея фотографий
* 📍 Контактная информация и расположение
* 📱 Адаптивная версия для мобильных устройств
* ✨ Плавные анимации и интерактивные элементы
* 🎨 Современный и минималистичный дизайн

## 🛠 Технологии

* HTML5
* CSS3
* JavaScript
* SVG
* Адаптивная вёрстка

## 📌 О проекте

Проект создан как концепт современного сайта для кофейни.

Основная задача — создать визуально привлекательный и удобный сайт, который передаёт атмосферу заведения, знакомит посетителя с меню и предоставляет всю необходимую информацию для посещения.

## 📱 Адаптивность

Сайт адаптирован для:

* 💻 Компьютеров
* 📱 Смартфонов
* 📲 Планшетов

## 📄 Примечание

Проект является демонстрационной работой для портфолио и может быть адаптирован под реальную кофейню, её фирменный стиль и требования.
